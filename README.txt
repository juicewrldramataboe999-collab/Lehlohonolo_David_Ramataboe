OPEN IN SPCK EDITOR
-------------------
1. Extract the ZIP archive on your phone or computer.
2. In SPCK Editor, open the extracted "lehlohonolo-portfolio" project folder.
3. Open index.html and use Preview/Run.
4. All five HTML pages link to the same css/style.css and js/main.js files.
5. To use your logo, copy your logo image into assets and name it exactly logo.png.
   Use a transparent PNG if possible. The website shows a simple "L" fallback if
   the logo image is missing.
6. In js/main.js, replace the empty social profile URLs with your real profile URLs.
7. Check all pages and links before publishing.
